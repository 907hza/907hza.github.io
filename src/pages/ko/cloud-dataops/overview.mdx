Kubernetes 구성요소와 동작 원리를 이해하고, 그 위에 데이터 인프라를 구축·운영하는 것이 목표입니다.

## 체크리스트

- [ ] **클라우드 1개 깊게**: AWS(S3, IAM, EC2, RDS, Glue, Athena, Redshift, EMR, MSK) 또는 GCP(BigQuery, GCS, Dataflow, Pub/Sub). IAM·네트워크(VPC)·비용 구조까지.
- [ ] **컨테이너**: Docker 이미지 최적화, Kubernetes(Pod·Deployment·Service·Resource limit), Helm.
- [ ] **IaC**: Terraform 기초.
- [ ] **CI/CD·DataOps**: GitHub Actions/GitLab CI로 파이프라인 코드 테스트·배포, 환경 분리(dev/prod).
- [ ] **관측성**: Prometheus·Grafana 모니터링, 로그 수집, 알림 설계.
- [ ] **폐쇄망·온프레미스 역량**: 제조·금융·공공 환경에서는 폐쇄망·온프레미스 K8s 운영이 중요합니다.

## 포트폴리오 3 · 플랫폼화

포트폴리오 1·2의 파이프라인을 Docker/Helm으로 K8s에 배포, Terraform·GitHub Actions·Grafana 모니터링 추가.
