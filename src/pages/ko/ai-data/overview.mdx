AI 개발 흐름을 이해하고, ML 학습 데이터와 RAG용 데이터를 다루는 파이프라인을 만드는 단계입니다.

## 체크리스트

- [ ] **ML 학습 데이터 파이프라인**: 대용량 학습·평가 데이터셋 버전 관리, 피처 스토어(Feast 등), GPU 인프라로의 전달.
- [ ] **비정형 데이터**: 문서·로그·이미지 파싱, 청킹, 임베딩 파이프라인.
- [ ] **RAG용 데이터**: 벡터 DB(pgvector, Milvus 등), 인덱싱·갱신 전략, 품질 평가.
- [ ] **MLOps 접점**: MLflow, Kubeflow, Ray 개념 수준.
- [ ] **AI 도구 활용**: AI로 데이터 업무를 자동화하는 경험을 쌓습니다. MCP·시맨틱 레이어로 셀프서비스 데이터를 제공하는 사례도 있습니다.

## 포트폴리오 4 · AI 확장

문서 데이터를 청킹·임베딩해 벡터 DB에 적재하는 RAG 데이터 파이프라인.
