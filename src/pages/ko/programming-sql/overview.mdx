모든 데이터 엔지니어링의 기본기입니다. 이 단계는 "능숙" 수준까지 올립니다.

## 체크리스트

- [ ] **SQL**: 조인, 집계, 서브쿼리, CTE, 윈도우 함수, 실행 계획 읽기. 프로그래머스 SQL 2단계 중상 수준을 기준선으로 삼습니다.
- [ ] **Python**: 알고리즘보다 데이터 처리 중심. pandas, 파일(CSV·JSON·Parquet) 처리, REST API 호출·인증·예외 처리, 로깅, 타입 힌트, pytest.
- [ ] **JVM 언어 (선택)**: Java/Scala/Kotlin 중 하나. 대규모 플랫폼·Kafka/Flink를 다룰 때 유리합니다.
- [ ] **Linux·Shell**: 프로세스·로그 확인, 권한, cron, ssh, 기본 쉘 스크립트.
- [ ] **Git**: 브랜치 전략, PR·코드 리뷰, 충돌 해결.

자격증(선택): SQLD/SQLP, ADP.
