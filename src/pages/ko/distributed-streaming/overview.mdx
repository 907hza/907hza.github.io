대용량 배치 처리(Spark)와 실시간 처리(Kafka·CDC·Flink)를 다룹니다. 실시간 스트리밍을 클라우드 네이티브 환경과 결합하는 것까지 목표로 합니다.

## 배치 분산처리

- [ ] **Spark**: DataFrame/SQL, 파티션·셔플, 조인 전략(broadcast/sort-merge), 데이터 스큐 처리, AQE, Spark UI로 병목 찾기.
- [ ] **쿼리 엔진**: Trino/Presto, Hive. 레거시 온프레미스 환경을 위해 Hadoop(HDFS·YARN)도 알아 둡니다.
- [ ] **파일 포맷**: Parquet·ORC·Avro, 압축, 파티셔닝·small file 문제.

## 스트리밍

- [ ] **Kafka**: 토픽·파티션·컨슈머 그룹, 오프셋, 복제, 전달 보장, Kafka Connect, Schema Registry.
- [ ] **CDC**: Debezium 등으로 운영 DB 변경분을 레이크에 반영. 이커머스·리테일에서 특히 많이 쓰입니다.
- [ ] **스트림 처리**: Flink 또는 Spark Structured Streaming. 윈도우, 워터마크, 상태 관리, exactly-once.
- [ ] **아키텍처**: Lambda vs Kappa, 늦게 도착한 데이터와 재처리 전략.

## 포트폴리오 2 · 실시간 CDC

PostgreSQL → Debezium → Kafka → Spark/Flink → Iceberg, Trino로 조회. 지연·정합성 측정 결과 정리.
